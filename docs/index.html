Under the Hood

How It Works

Fully local. No accounts, no servers, no data sent anywhere.

01

Client Detection

RiftVault uses PowerShell and WMI to locate your League lockfile across all drives and authenticate against the local LCU API — automatically, with no manual setup.

02

Inventory Fetch

Your owned skins, mastery points, and inventory data are pulled live from the League client's local API. Nothing is sent externally.

03

Asset Enrichment

Champion metadata, rarity classifications, and splash arts are pulled from Riot's Data Dragon CDN and CommunityDragon — cross-referenced for accuracy.

04

Local Cache

Everything is stored in your AppData directory for instant offline access. No cloud, no tracking, no accounts.

LCU API

League Client Update API — official local API that powers the client itself. Used for live inventory and champion select skin application.

Data Dragon (DDragon)

Riot's official CDN for champion metadata, tile splash arts, and profile icons. Always up-to-date with the latest patch.

CommunityDragon (CDragon)

Community-maintained data source for authoritative rarity classifications, vault status, and additional UI assets not in DDragon.

Electron + Node.js

Cross-process desktop app built with Electron. Main process handles LCU comms and data aggregation; renderer handles all UI.
